# Agent branding screenshots

These are actual simulator captures of the app's sign-in and agent setup screens, with no signed-in account or customer data. JPEG files use RGB with no alpha channel.

The iPhone 18 Pro Max captures are 1320 × 2868 and use the App Store Connect `APP_IPHONE_67` screenshot set.

Recommended order:

1. `iphone-agent-sign-in.jpg`: Your food log. Your AI agent.
2. `iphone-agent-setup.jpg`: Bring your own agent; ChatGPT Work setup.
3. `iphone-agent-events.jpg`: Instructions and event subscriptions.

00Food targets iPhone only; no iPad screenshot set is maintained. Store text is maintained in [app-store.json](../app-store.json).
