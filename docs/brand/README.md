# 00Food identity

00Food keeps the 00Widget and 00Todo two-card agent, white fedora, slashed-zero eyes, blue edge, and teal accent. A plate and cutlery replace the chart or task-row mouth. A warm coral field distinguishes its icon from its siblings. The wordmark uses the same blue `00` and Avenir Next typography.

The generator uses Pedro Morais's approved 00Widget master artwork in `sources/` and produces the app icon, in-app mark, wordmarks, and preview. Run `python3 docs/brand/generate.py` from the repository root. The original masters and derived assets have separate licenses in this directory.
